1. Установка

npm i @open-slot-ui/core @open-slot-ui/pixi pixi.js

Нужен один общий экземпляр pixi.js (peer-зависимость). GSAP не обязателен, но включает авто-уменьшение широких сумм в счётчике.

2. Быстрый старт

Весь HUD монтируется одним вызовом mountHud(app, spec, opts) поверх уже существующего Pixi-приложения.

import { Application } from 'pixi.js';
import { mountHud } from '@open-slot-ui/pixi';

const app = new Application();
await app.init({ resizeTo: window, backgroundAlpha: 0 });
document.body.appendChild(app.canvas);

const hud = mountHud(app, {
  currency: { code: 'USD', symbol: '$', display: 'symbol', position: 'prefix', decimals: 2 },
  betLadder: { levels: [0.5, 1, 2, 5, 10, 20], index: 1 },
});
const ui = hud.ui;

ui.balance.set(1000);

// Игра слушает запросы HUD и крутит барабаны:
ui.on('spinRequested', async () => {
  if (ui.balance.get() < ui.bet.get()) { hud.showRgsError('ERR_IPB'); return; }
  ui.spin.busy();
  ui.balance.set(ui.balance.get() - ui.bet.get());
  await playRound();            // ваша логика барабанов
  const win = /* ... */ 0;
  ui.balance.set(ui.balance.get() + win);
  ui.reportRound(win, ui.bet.get()); // net / автоигра / лимиты
  ui.spin.idle();
});

3. Как HUD общается с игрой

Правило простое: HUD рисует и шлёт события — игра выполняет логику и обновляет данные.

  • Наружу (события): ui.on('spinRequested', ...), 'autoplayStarted', 'skipRequested' и т.д.
  • Внутрь (фасад): ui.balance.set(), ui.spin.busy()/idle(), ui.reportRound(), hud.showError().

4. UISpec — конфигурация

Второй аргумент mountHud — декларативный объект. Все поля необязательны.

mountHud(app, {
  // деньги
  currency: { code:'USD', symbol:'$', display:'symbol', position:'prefix', decimals:2 },
  betLadder: { levels:[0.5,1,2,5,10,20], index:1 },

  // спин / турбо
  spin:  { press: 'tap' | 'hold-to-spin' },
  turbo: { index: 0 },              // турбо: только 2 режима (выкл/вкл)

  // автоигра
  autoplay: {
    mode: 'options' | 'infinite',
    options:    [5, 10, 25, 50, 100, Infinity],
    lossLimits: [10, 25, 50, Infinity],   // необязательно (RG)
    winLimits:  [25, 50, 100, Infinity],  // необязательно (RG)
  },

  // регуляторика
  rtp: 96,
  jurisdiction: { /* см. §9 */ },
  realityCheck: { everyMinutes: 60 },

  // презентация
  theme: 'default' | { color?, radius?, type?:{ family? } },
  responsive: { portrait?:{controls}, landscape?, mobile?, tablet?, desktop? },
  controls: { [id]: { layout?, label?, hidden?, disabled?, currency?, initial?, digits? } },
  menu: { settings?: Block[], paytable?: Block[], rules?: Block[] },
  audio: { startMuted: false },

  // локализация
  locale: { locale:'ru', messages:{...}, socialMessages:{...} },
  social: true | { coin:'GC' },
  game: { name:'Моя игра', version:'1.0.0' },
}, {
  // опции рендерера
  intro: 'shown' | 'hidden' | 'slide-in',
  autoplayPicker: 'drawer' | 'radial',
  gsap,                              // включает авто-уменьшение широких сумм
  spinSkin,                         // своя графика кнопки спина
  icons: { turboOff, turboOn, autoIdle, autoActive, bonus, betPlus, betMinus },
});

5. Элементы управления

На экране: spin · autoplay · turbo · bet-minus · bet-plus · bonus (Buy) · settings (☰) · mute · fullscreen · balance · bet · rtp · net-position · session-timer.

Позиция любого — через controls[id].layout = { anchor, offset:[x,y], scale?, rotation? }. Опорные кадры: ландшафт 1920×1080, портрет 1080×2337 (offset в опорных px, масштабируется под экран).

RTP / Net / Session Time — это только полупрозрачный блок в левом-верхнем углу. Плашки-хедера/футера нет. Показываются флагами юрисдикции (см. §9).

6. Автоигра

Полностью настраивается. Задаёте варианты числа спинов; два поля лимитов (стоп по проигрышу / по выигрышу) появляются, только если их указать.

autoplay: {
  mode: 'options',                     // тап открывает выбор; 'infinite' — сразу ∞
  options: [10, 25, 50, 100, Infinity],
  lossLimits: [10, 25, 50, Infinity],  // «Стоп при проигрыше N×ставки» (опц.)
  winLimits:  [25, 50, Infinity],      // «Стоп при выигрыше ≥ N×ставки» (опц.)
}

Во время автоигры кнопка автоигры становится жёлтой (неактивной), а кнопка спина превращается в STOP N (для ∞ — «STOP ∞») и останавливает автоигру. Игра обязана вызывать ui.reportRound(win, bet) после каждого раунда — счётчик и лимиты работают на этом.

7. Кнопка бонуса (Buy Feature)

Кнопка Buy скрыта по умолчанию. Если в игре нет покупки функции — кнопка не показывается. Чтобы включить: controls: { bonus: { hidden: false } } или в рантайме ui.setHidden('bonus', false).

Модалка Buy Feature задаётся конфигом: до 4 вариантов, каждый — либо покупаемый (buy), либо активируемый бонус (boost). Для Stake активируемые могут быть взаимоисключающими (activation:'single'). У каждого варианта — ключ, картинка и цена.

const FEATURES = [
  { id:'freespins', kind:'buy',   name:'Free Spins',   cost:100, image:'https://cdn/…/fs.png' },
  { id:'super',     kind:'buy',   name:'Super Spins',  cost:300, image:'https://cdn/…/super.png' },
  { id:'ante',      kind:'boost', name:'Ante Bet',     cost:0.25, image:'https://cdn/…/ante.png' },
  { id:'double',    kind:'boost', name:'Double Chance',cost:0.5,  image:'https://cdn/…/dc.png' },
];
// activation:'single' → активируемые взаимоисключающие (Stake)

8. Меню и правила

Отдельной кнопки «Правила» нет. Кнопка ☰ открывает один прокручиваемый лист с секциями по порядку: настройки → пейтабл → правила. Каждую наполняете «блоками»; весь текст проходит через ui.t() (локализуется). Меню всегда светлое (тема не делает его тёмным).

menu: {
  settings: [
    { kind:'toggle', id:'sound', label:'openui.sound' },
    { kind:'select', id:'lang',  label:'openui.language',
      options:[{value:'ru',label:'Русский'},{value:'en',label:'English'}] },
  ],
  paytable: [
    { kind:'paytable', id:'pt', columns:3, rows:[
      { symbol:'Wild', icon:'…/wild.png', payouts:'5× = 50\n4× = 20\n3× = 5' },
    ]},
  ],
  rules: [
    { kind:'heading', id:'r1', text:'Как играть' },
    { kind:'text',    id:'r2', text:'Соберите **3 и более** символов на линии.' },
    { kind:'steps',   id:'r3', ordered:true, items:['Выберите ставку ±','Нажмите спин','Выплаты слева направо'] },
    { kind:'stat-grid', id:'r4', items:[{label:'RTP',value:'96.0%'},{label:'Макс. выигрыш',value:'5000×'}] },
    { kind:'image',   id:'r5', src:'…/reels.png', width:1000, height:400 },
  ],
}

Виды блоков: heading, subheading, text (поддержка **жирного** и \n), legal, divider, callout, stat-grid, table, cards, paytable, image, media, steps, group; интерактивные: toggle, slider, select, stepper, button, value.

В модалках (ошибка/уведомление) «callout»-плашек нет — только заголовок и текст. Блок callout используется только в меню.

Открыть из кода: ui.settingsButton.activate() или ui.settingsPanel.openPanel()/closePanel().

9. Регуляторная конфигурация

Объект jurisdiction (обычно из ответа RGS) — один вызов ui.applyJurisdiction(cfg) или поле jurisdiction в spec.

ФлагДействие
displayRTPпоказать RTP
displayNetPositionпоказать net (баланс сессии)
displaySessionTimerпоказать таймер сессии
disabledTurboскрыть/выключить турбо
disabledAutoplayскрыть/выключить автоигру
disabledSlamstopзапретить тап-стоп во время спина
disabledSpacebarзапретить спин с клавиатуры и hold-to-spin
disabledBuyFeatureскрыть/выключить Buy
disabledFullscreenскрыть полноэкранный режим
socialCasinosocial-режим (см. §10)
minimumRoundDurationмин. длительность раунда (мс) — соблюдает игра

Ответственная игра: reality check (RTS 13), лимиты автоигры (по проигрышу / одному выигрышу / числу спинов), авто-стоп при недостатке средств, коды ошибок RGS (hud.showRgsError('ERR_IPB') и т.п.). Проверка флага в коде: ui.isDisabled('autoplay').

10. Локализация и social-режим

Встроенный словарный переводчик, 16 локалей Stake, подстановка {{minutes}}. Переключение: ui.setLocale('ru') (или select в меню). Ключи без перевода отображаются как есть.

locale: {
  locale: 'ru',
  messages: { ru: { 'openui.spin':'Крутить', 'openui.bet':'Ставка' } },
  // ОТДЕЛЬНЫЙ словарь для social-режима — нельзя перепутать с обычным
  socialMessages: { ru: { 'openui.bet':'Игра', 'openui.balance':'Кредиты' } },
}
Social-локализация задаётся отдельным словарём locale.socialMessages (те же ключи). В social-режиме он используется в первую очередь — так по дизайну исключено смешивание обычных и social-текстов. Включение: ui.setSocial(true, 'GC').

11. Тема

Одна встроенная тема — default (чёрно-белая с жёлтым акцентом). Хост может переопределить только безопасное подмножество: цвета, радиусы и семейство шрифта. Некорректные значения отбрасываются (HUD не ломается).

theme: { color: { accent: '#ffcc00' }, type: { family: '"Montserrat", sans-serif' } }

12. События

Подписка: ui.on(type, fn). Основные:

spinRequested · skipRequested · holdSpinStarted · holdSpinStopped · autoplayStarted · autoplayStopped · turboChanged · toggled · buttonActivated · cardActivated · valueChanged · optionSelected · panelToggled · stateChanged · visibilityChanged · localeChanged · realityCheck · noticeShown · noticeDismissed.
